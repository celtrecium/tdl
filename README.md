# Text Drawing Library
TDL is a library for drawing with text using user-friendly API

## clone
  Due to the use of submodules, you need to clone the repository as \
  follows:
  ```
  git clone --recurse-submodules https://github.com/celtrecium/tdl
  ```

## build and install
  - build as a static library
  ```
  make static
  ```
  - build as a shared library
  ```
  make shared
  ```
  - build everything
  ```
  make
  ```
  - install
  ```
  make install
  ```
  - uninstall
  ```
  make uninstall
  ```
